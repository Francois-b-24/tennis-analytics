# Notebooks

Notebooks d'exploration, nommés `<numéro>-<initiales>-<description>.ipynb`
(convention cookiecutter-data-science), par exemple `01-fb-exploration-elo.ipynb`.

Le code stabilisé migre vers `src/tennis_analytics/` pour être testé et réutilisé
par l'application — un notebook n'est jamais une dépendance de `app/`.
